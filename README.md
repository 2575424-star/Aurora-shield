# Realty Monitor

Новый проект мониторинга объявлений квартир Авито и Циан.

## Состояние
Первый этап: веб-API и хранилище объявлений, история цен, расчёт цены за м² и сравнение с медианой сопоставимых квартир. Подключение внешних источников данных — следующий этап. **Автоматический сбор с Авито и Циан пока не подключён.**

## Локальный запуск
```bash
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

Swagger: `/docs`, health: `/health`.

## Railway
Dockerfile готов. Для постоянного хранения укажите `DATABASE_PATH` на подключённом томе (например, `/data/realty.db`). Для production рекомендуется PostgreSQL и авторизация API.

## API
- `POST /listings` — загрузить/обновить объявление из разрешённого источника
- `GET /listings` — получить объявления, фильтр по минимальному дисконту
- `GET /listings/{source}/{external_id}/history` — история изменения цены
- `GET /stats` — агрегаты

Оценка дисконта — предварительная, по медиане объектов того же города, комнатности и типа рынка; не является оценкой рыночной стоимости.

Исходный проект, который изучается как возможный источник модулей сбора: https://github.com/parallelograffi4eskiy/parser_avito_cian . Не копируйте его cookies, токены или тестовую БД. Проверяйте лицензии и условия площадок.

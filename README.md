# Realty Monitor — проверка источников

Проект мониторинга объявлений о недвижимости. Исходный API: `app.py`; диагностика доступности публичных страниц: `probe.py`.

## Тест Авито и Циан
При старте сервиса однократно выполняется тест HTTP-доступности страниц аренды квартир в Воронеже. Результат — `GET /probe/status` и логи Railway. `GET /probe/run` повторяет тест по запросу (не чаще раза в 60 секунд). Тест определяет HTTP-статус и наличие ссылок на объявления; **это не полноценный парсер карточек**.

## Дальше
Оригинальные модули, которые изучаем для интеграции: https://github.com/parallelograffi4eskiy/parser_avito_cian . Они требуют Playwright, cookies и ряда локальных модулей. Подключать их к рабочему сервису следует после отдельного теста совместимости и проверки лицензии. Нельзя копировать чужие cookies и токены.

## Railway
Dockerfile в корне. Переменная `REALTY_API_KEY` обязательна для `POST /listings`. SQLite без volume не обеспечивает сохранность данных при пересборке; далее подключим постоянную базу.

## API
`GET /health`, `GET /probe/status`, `GET /probe/run`, `POST /listings`, `GET /listings`, `GET /stats`.
